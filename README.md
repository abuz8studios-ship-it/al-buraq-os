# Al Buraq OS (historic release)
An early 2026 ABUZ8 LLC experiment: a self-contained agentic OS scaffold ("Spark" build) with a local model power-pack lane.
Released as-is for study and reuse (MIT). The 8B GGUF power-pack is NOT included (model weights carry their own licenses — bring your own GGUF and point powerpacks/ at it).
Built by Ahmad Odeh with Claude (Anthropic) as pair engineer. Part of the lineage that became ABUZ8 OS — see abuz8ai.com.
